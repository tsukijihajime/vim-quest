# VimQuest

ブラウザで動く Vim 学習ゲーム。**遊ぶ → https://tsukijihajime.github.io/vim-quest/**

ゲーム盤は本物のテキストバッファである。`w` は次の単語頭へ、`dw` は単語を消す —
実際の Vim と同じ意味論で動くので、ここで覚えた操作はそのまま Vim で使える。
全 18 ステージで `hjkl` の移動から `d` `c` `y` `p` の編集までを段階的に扱う。

## 遊び方

各ステージには目標と、そこで新しく使えるようになるキーがある。
光っているマスを全部踏むか、バッファを目標の形に書き換えるとクリア。
打鍵数が少ないほど星が増える（想定した最短手順以下で ★★★）。
`Tab` で一覧に戻る。進行はブラウザに保存される。

## 開発

```bash
npm install

```

## 構成

依存は一方向にのみ流れる。

```
ui  →  game  →  stages
                  ↓
                core   （どこにも依存しない）
```

`src/core/` が Vim エンジンで、DOM に一切触れない。中心は
`applyKey(state, key): EditorState` という純粋関数ひとつで、17 のモーションと
`x d c y p P r u`・挿入モードの意味論がすべてこの背後にある。
だからブラウザを起動せずに全挙動をテストできる。

`src/stages/` はステージ定義と JSON ローダ。`par`（★★★ の基準打鍵数）はデータに
持たせず想定解から導出するので、二重管理で食い違うことがない。
`src/game/` がゴール判定・打鍵計数・星評価・進行保存、`src/ui/` が描画と入力を持つ。

設計の詳細は [docs/superpowers/specs/](docs/superpowers/specs/) にある。

## Vim Adventures との関係

Vim Adventures に着想を得ているが、実装は全て独自のもので、素材も設計も流用していない。
あちらはタイルマップの迷路、こちらは本物のテキストバッファという点で中核設計から異なる。

Vim 本体のソースコードも参照しておらず、公開されている挙動仕様から再実装している。
